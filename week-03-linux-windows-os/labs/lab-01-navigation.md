# Lab 01: Linux navigation (Kali)

**Setup**
```
mkdir -p ~/week3-lab && cd ~/week3-lab
```

**Tasks**
1. `pwd` → where am I? Then `cd /` and `ls -l`. Name five directories you see.
2. `cd /etc && ls | head`, then `cd ~` and `cd -` (what does `-` do?).
3. `ls -la ~` → what are the hidden files (starting with `.`)?
4. `cat /etc/os-release` and `uname -a` → record the distro and kernel.
5. `man ls` (quit with `q`), then `ls --help | head`. Find what `-h` does.
6. `ls /var/log` → list three log files.
7. Practise absolute vs relative: from `~/week3-lab`, reach `/etc/hostname` using a relative path (`../../etc/hostname` style) and an absolute one.
