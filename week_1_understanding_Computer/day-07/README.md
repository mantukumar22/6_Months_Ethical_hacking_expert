# Day 07 — Review + Mini Project: System Baseline Report

## Review (30 min)
Without looking back, explain: the I-P-M-S-O chain, CPU/RAM/storage roles, layer model, what an OS does, program vs process, absolute vs relative path.

## Mini project (60 min)
Create `baseline-report.md` documenting a "normal" state of your machine:
1. Specs (from Day 2)
2. Top 10 processes with PID/parent (Day 5)
3. `ipconfig` summary (Day 4)
4. Key folder layout you created (Day 6)
5. 3 things that would look suspicious, and why

2. Give an example vulnerability at each of the 4 layers.
3. What makes `powershell.exe` suspicious?
4. Why does least privilege reduce damage?
5. Name 3 places malware may hide.
