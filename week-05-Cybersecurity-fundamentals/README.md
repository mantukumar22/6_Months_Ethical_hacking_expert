# Week 5: Cybersecurity Fundamentals

**1 hour/day · Beginner level**

Goal: understand core cybersecurity concepts before moving into VAPT. By the end of the week I can explain the **CIA Triad, threats, vulnerabilities, risks, exploits, attack surfaces and security controls**.

> **Safety rules**
> - Practice only on intentionally vulnerable apps I run myself (OWASP Juice Shop on localhost) or in TryHackMe rooms. Never test real websites or other people's systems without written permission.
> - Never commit passwords, tokens or personal data in lab evidence. Crop or redact screenshots.
