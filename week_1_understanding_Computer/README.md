# Cybersecurity Foundations — 7 Days

A hands-on, day-by-day repo for learning how computers work **from a security point of view**.
Every day has: concepts explained, a practical, a cybersecurity connection, and a notes file you fill in **in your own words**.

| Day | Topic | Security takeaway |
|-----|-------|-------------------|
| 01 | How a computer works | Know the parts before you defend them |
| 02 | CPU, RAM & Storage | Malware uses resources — know "normal" |
| 03 | Hardware vs Software | Vulnerabilities live at every layer |
| 04 | Operating Systems | The OS enforces security boundaries |
| 05 | Processes & Programs | Process analysis = SOC / IR foundation |
| 06 | Filesystems | Permissions, hidden files, persistence |
| 07 | Review + mini project | Tie it together, build a system baseline |

## How to use
1. Open the day's `README.md`, read **Learn**.
2. Do the **Practical**, saving outputs in that day's `evidence/` folder.
3. Fill `notes.md` in your own words (no copy-paste).
4. Commit daily: `git commit -m "Day 0X complete"`.

> Only run commands on your own machine / VM. Never scan or probe systems you don't own.
