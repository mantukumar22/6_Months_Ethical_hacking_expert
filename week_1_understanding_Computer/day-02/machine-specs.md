# My Machine
- CPU: The brain of the computer. it executes instructions from programs: opening apps, running calculations, handling the operating system. when you see a listing like "Intel Core i7-13700" or "AMD Ryzen 77700X", that's the CPU model. Higher genration numbers and higher tiers (i3 < i5 < i7 < i9, or Ryzen 3 < 5 < 7 < 9) generally mean more performance. Clock speed (in GHz) tells you how fast each core runs, but it isn't the whole story, since newer architecture do more work per cycle.
- Cores: A core is an independent processing unit inside the CPU. More cores means the CPU can work on more task truly in parallel. A 4-core CPU handles everyday tasks fine, 6-8 cores suit gaiming and multitasking. Some modern CPUs mix "performance" cores and "efficency" cores to balance speed and power use. 
- Logical processors: This is the number of "threads" your operating system sees. With technologies like Intel's Hyper-Threading or AMD's SMT, each physical core can handle two threads at once, so an 8-core CPU often shows 16 logical processors. It's not the same as having twice the cores (the gain is usually 20-30% on heavy multithreaded work), but it helps the CPU stay busy. If cores and logical processors are equal, the CPU has no multithreading.
- RAM: Fast, temporary memory that holds the data your programs are actively using. It's wiped when you power off. More RAM lets you keep more apps, browser tabs, and files open without slowdowns.

  8 GB: basic use, light multitasking
  16 GB: the comfortable standard for most people and gaming
  32 GB+: heavy editing, development, virtual machines, large datasets

Speed (e.g., DDR4 vs. DDR5, MHz) also matters, but capacity is usually the first thing to check.
- Storage type: This is where your files, OS, and programs live permanently. The type strongly affects how fast the computer feels.

  HDD (hard disk drive): spinning magnetic platters. Cheap and large, but slow and sensitive to shocks.
  SSD (SATA): no moving parts, much faster than an HDD, and a big upgrade for boot and load times.
  NVMe SSD: plugs into an M.2 slot and is several times faster than SATA SSDs. This is the best option for modern systems.

Capacity (256 GB, 512 GB, 1 TB, etc.) is separate from type.
- GPU: The processor dedicated to graphics and highly parallel math. It renders games, video, and 3D, and it's also used for video editing acceleration and AI/machine learning.

  Integrated GPU: built into the CPU and shares system RAM. It's fine for web browsing, video, and light gaming.
  Dedicated GPU: a separate card (NVIDIA GeForce/RTX, AMD Radeon) with its own memory (VRAM). It's needed for serious gaming, 3D work, and AI tasks.

VRAM (e.g., 8 GB, 12 GB) matters a lot for high resolutions, big textures, and AI models.
