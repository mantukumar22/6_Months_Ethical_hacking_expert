# Day 01 — How does a computer actually work?

## The chain
`Input → Processing → Memory → Storage → Output`
You type (input), the CPU works on it (processing), data sits in RAM while in use (memory), is saved to disk (storage), and you see the result (output).

## Learn (explained simply)
- **Computer**: a machine that follows instructions on data.
- **CPU**: the "brain" — executes instructions one tiny step at a time, very fast.
- **RAM**: fast, temporary workspace. Wiped when power goes off.
- **Storage**: long-term holding place (files, OS, apps). Survives shutdown.
- **Motherboard**: the main board connecting everything.
- **I/O devices**: keyboard, mouse, screen, speakers, network card.
- **Binary**: everything is 1s and 0s — text, images, programs, malware.
- **Software ↔ hardware**: software never touches hardware directly; the OS and drivers sit in between.

## Cybersecurity perspective
Every attack targets some part of this chain: stealing **input** (keyloggers), abusing **processing** (malicious code), reading **memory** (credential dumping), encrypting **storage** (ransomware), or exfiltrating **output** (network).
